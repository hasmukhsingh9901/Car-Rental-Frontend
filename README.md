# 🖥️ Car Rental App – Frontend (Next.js)

This is the frontend for the Car Rental MERN Stack App built using **Next.js App Router**, **Tailwind CSS**, and **ShadCN UI**. Users can view, filter, rent. Admins can manage cars through a dashboard.

---

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, ShadCN UI
- **Forms & Validation:** Native form handling
- **HTTP Requests:** Axios
- **Auth:** JWT (via localStorage)
- **Routing:** Client-side navigation using Next.js
